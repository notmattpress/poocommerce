The current and recommended version of the PooCommerce REST API. Use `/wp-json/wc/v3/` endpoints for all new integrations.

When WooPayments is active, it adds `/wp-json/wc/v3/payments/` endpoints for payment reports, authorizations, and payouts. See the [WooPayments REST API reference](https://automattic.github.io/poocommerce-payments/) for their response formats.
